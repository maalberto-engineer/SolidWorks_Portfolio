# Publishing this portfolio on GitHub

1. Create a new public GitHub repository, for example `solidworks-portfolio`.
2. Upload the contents of this folder. The `README.md` will become the repository landing page automatically.
3. Before publishing, replace the Contact placeholder in `README.md` and `index.html` with your preferred email, LinkedIn, and GitHub profile.
4. Optional: enable **Settings -> Pages -> Deploy from a branch -> main / root**. GitHub Pages will then use `index.html` as a standalone portfolio site.
5. Keep the original recovered USB archive backed up separately; this portfolio contains selected copies rather than replacing your originals.

## Notes
- The portfolio uses MP4 previews rather than AVI for browser compatibility and much smaller file sizes.
- Native `.SLDASM` and `.SLDPRT` files are preserved inside each project folder for employers who want deeper review.
- If an assembly references files that are not present, open the project locally and use SOLIDWORKS Pack and Go before replacing the portfolio copy.
